ABOUT DROPSTAR

Small tasks, made simpler.

Dropstar is a browser-based toolbox for useful everyday tasks. No app installation is needed. Tools that handle files, such as image compression and PDF merging, run locally in your browser. Some features load open-source libraries from a CDN and therefore need an internet connection.

What you can do on Dropstar

Use handy browser tools for everyday calculations, text editing, image compression, QR codes and PDFs. We aim to keep the experience simple, responsive and accessible on desktop and mobile.

Privacy and responsible use

Most tools process your input in your browser. Avoid entering confidential information into any online tool unless you understand how it works. The password vault is a starter utility, not a replacement for a professionally audited password manager.
